# Paradise Nursery Shopping Application

Paradise Nursery is an e-commerce React application designed for plant lovers. It provides an intuitive shopping experience allowing users to browse various categories of houseplants, add them to a shopping cart, adjust item quantities, and view real-time subtotal and total calculations managed via Redux Toolkit.

## Project Features
- **Landing Page**: Introduction page with a get started option.
- **Product Listing**: Categorized displays of plants with dynamic cart integration.
- **Shopping Cart**: Real-time quantity updates, item deletions, and price aggregation.
- **State Management**: Implemented using React-Redux.
